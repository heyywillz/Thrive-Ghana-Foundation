# Thrive Ghana Foundation

Thrive Ghana Foundation is a non-profit organization dedicated to empowering vulnerable communities, women, girls, and youth across Ghana. This repository hosts the official website and digital resources for the foundation, focusing on community development, education, clean water access, healthcare, and leadership initiatives.

## About the Foundation

Thrive Ghana Foundation works to address pressing socio-economic challenges in underserved regions of Ghana. Through targeted programs, clean water borehole installations, educational assistance, healthcare support, and youth empowerment workshops, the foundation strives to create sustainable, positive change.

## Key Features

- **Responsive Design**: Mobile-first, fully adaptable layout across desktop, tablet, and mobile screens.
- **Modern UI**: Styled with Tailwind CSS, custom color themes, and Font Awesome icons.
- **SEO and Social Metadata**: Configured with Open Graph protocol tags, Twitter Cards, and JSON-LD structured schema for search engines.
- **Fast Performance**: Optimized image assets in WebP format and lightweight client scripts.
- **Interactive UI**: Custom JavaScript for mobile navigation, interactive elements, and modal handlers.

## Website Structure

- `index.html`: Main landing page featuring mission highlights, core pillars, impact stats, and testimonials.
- `about.html`: Foundation background, vision, leadership team, and values.
- `events.html`: Information on upcoming community outreach, workshops, and past initiatives.
- `gallery.html`: Media showcase of field operations and community projects.
- `news.html`: News articles, announcements, press releases, and updates.
- `contact.html`: Interactive contact form, location address, telephone, and email details.
- `style.css`: Custom CSS stylesheets supplementing Tailwind utility classes.
- `script.js`: Client-side logic for dynamic interactions and DOM manipulations.
- `assets/`: Image assets, logos, and media files.

## Technologies Used

- **HTML5**: Semantic markup for accessibility and web standards.
- **Tailwind CSS**: Utility-first CSS framework for rapid styling.
- **CSS3**: Custom styles, responsive tweaks, and smooth transitions.
- **JavaScript (ES6+)**: Vanilla client-side script for interactive components.
- **Font Awesome**: Icon library for visual indicators.
- **JSON-LD**: Schema.org metadata for non-profit organization structured data.

## Getting Started

### Prerequisites

To run or edit this project locally, you need a modern web browser and optionally a local static server or code editor.

### Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/heyywillz/Thrive-Ghana-Foundation.git
   ```

2. Navigate into the project directory:
   ```bash
   cd Thrive-Ghana-Foundation
   ```

3. Open `index.html` in your web browser or run a local server:
   ```bash
   npx serve .
   ```

## Deployment

This website is configured for deployment on [Vercel](https://vercel.com). Pushes to the `main` branch automatically trigger build and deployment workflows.
